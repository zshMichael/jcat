# Jcat 1.2.1

安装包没有 Apple 公证，也没有 Windows 签名。发布里的 `SHA256SUMS.txt` 可以用来核对下载文件。

---

## 中文

Mac 安装包窗口里有一份「先读我」。把 Jcat 拖进「应用程序」后，在终端执行：

```
xattr -cr /Applications/Jcat.app
```

系统若说文件已损坏，点取消，不要移到废纸篓。

安装包：

- `jcat-1.2.1.dmg` — macOS Apple Silicon
- `jcat-1.2.1-x64-setup.exe` — Windows x64
- `jcat-1.2.1-arm64-setup.exe` — Windows ARM64
- `jcat-1.2.1-setup.exe` — Windows 自动识别（含 x64 与 ARM64）

## English

The Mac disk image includes a note. After dragging Jcat to Applications, run:

```
xattr -cr /Applications/Jcat.app
```

If macOS says the app is damaged, click Cancel.

Installers:

- `jcat-1.2.1.dmg` — macOS Apple Silicon
- `jcat-1.2.1-x64-setup.exe` — Windows x64
- `jcat-1.2.1-arm64-setup.exe` — Windows ARM64
- `jcat-1.2.1-setup.exe` — Windows auto-detect (x64 and ARM64)

## 한국어

Mac 설치 창에 안내 파일이 있습니다. Jcat을 응용 프로그램으로 옮긴 뒤 터미널에서 실행합니다.

```
xattr -cr /Applications/Jcat.app
```

손상되었다는 창이 뜨면 취소를 누르세요.

설치 파일:

- `jcat-1.2.1.dmg` — macOS Apple Silicon
- `jcat-1.2.1-x64-setup.exe` — Windows x64
- `jcat-1.2.1-arm64-setup.exe` — Windows ARM64
- `jcat-1.2.1-setup.exe` — Windows 자동 인식(x64와 ARM64)
